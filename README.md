# ChatGPT Russia — Android project

Неофициальный клиентский прототип с русским интерфейсом, Kotlin + Jetpack Compose.

## Сборка APK через GitHub (без установки Android Studio)

В проект уже добавлен GitHub Actions workflow для автоматической сборки APK.

1. Создайте новый пустой репозиторий на GitHub.
2. Распакуйте этот архив и загрузите всё содержимое папки `ChatGPTRussia` в репозиторий.
3. Откройте вкладку **Actions** в репозитории.
4. Выберите **Build Android APK** и нажмите **Run workflow** (если сборка не запустилась автоматически после загрузки).
5. После успешной сборки откройте запуск workflow и скачайте артефакт **ChatGPT-Russia-debug-apk**.
6. Распакуйте скачанный артефакт — внутри будет `app-debug.apk`. Перенесите APK на Android-телефон и установите его, разрешив установку из этого источника.

## Что реализовано
- чат-интерфейс на русском языке;
- новый диалог;
- отправка сообщений;
- настройка URL, модели и API-ключа;
- подключение к OpenAI-совместимому Chat Completions API.

## Важно
Это не официальное приложение OpenAI. Для настоящих ответов нужен API-ключ и доступный API endpoint. Доступность OpenAI API и способов оплаты в России может быть ограничена. Без API-ключа приложение установится, но не сможет получать настоящие ответы модели.

API-ключ в текущем прототипе хранится только в памяти приложения и исчезает после его закрытия. Не встраивайте секретный ключ в публично распространяемый APK; для массового использования лучше подключить собственный сервер-посредник.

Минимальная версия Android: 8.0 (API 26).
